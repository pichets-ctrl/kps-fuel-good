📦 นำเข้าสต๊อกน้ำมัน

อัปเดตข้อมูลสต๊อกน้ำมันได้หลายวิธี เลือกวิธีที่สะดวกสำหรับคุณ

📷 นำเข้าจากภาพถ่าย

ถ่ายภาพหน้าจอโปรแกรมสต๊อก หรืออัปโหลดไฟล์ภาพ แล้วกรอกค่าที่ระบบอ่านได้

📸

แตะเพื่อถ่ายภาพ หรือเลือกไฟล์

รองรับ JPG, PNG, HEIC · สูงสุด 10 MB

💡 วิธีใช้: กรอกค่าจากภาพด้านล่าง

ดูค่าเปอร์เซ็นต์สต๊อกจากภาพ แล้วปรับ Slider แต่ละน้ำมันด้านล่าง ระบบ OCR อัตโนมัติจะพร้อมใช้งานในเวอร์ชันถัดไป

✏️ กรอกข้อมูลเอง

ปรับ slider หรือพิมพ์ตัวเลขเปอร์เซ็นต์สต๊อกน้ำมันแต่ละชนิด

💡 เคล็ดลับ: แตะปุ่ม คัดลอกจากสต๊อกล่าสุด เพื่อโหลดค่าเดิมก่อนแก้ไข
🔗

Webhook (POST)

ส่งข้อมูลสต๊อกจาก IoT sensor, PLC หรือโปรแกรมเดิมผ่าน HTTP POST

POST https://kps-fuel-good.web.app/api/stock
📡

IoT Sensor

เชื่อมต่อ sensor วัดระดับน้ำมัน (ultrasonic, float) ผ่าน ESP8266/ESP32

API Key: กรุณาเลือกปั๊มก่อน
📊

นำเข้าไฟล์ CSV

Export ข้อมูลจากโปรแกรมสต๊อกเดิม แล้วอัปโหลดไฟล์ .csv
